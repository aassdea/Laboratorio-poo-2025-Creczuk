# Laboratorio-poo-2025-Creczuk
Para esta tarea, van a tomar el ejercicio de práctica de UML de Polimorfismo y lo van a trasladar completamente funcional a Java, utilizando tanto prints como estructuras y operadores del mismo lenguaje.Debe haber en la entrega:
Uso del paquete instanciado en el archivo.
Declaración de clase abstracta Notificación (depende de sus clases hijas para hacerse un objeto).
Declaración de la clase Notificación SMS con su herencia instanciada.
Declaración de la clase 
Notificación Push con su herencia instanciada.
Declaración de la clase Notificación E-Mail con su herencia instanciada.
Declaración de atributos para cada clase, estableciendo los heredados con un super().
Método constructor para cada clase.
Getters y setters.
Métodos de cada clase funcionales. Método enviar() sobreescrito en las clases hijas para que al saludar muestre los atributos distintos de cada una.
Clase Main que cree un objeto para los 3 tipos de notificaciones. Todas las clases deben ser funcionales. 
Para ello, entregar estos archivos: Notificacion.java, NotificacionSMS.java, NotificacionPush.java, NotificacionEMail.java, Main.java.
