# Laboratorio-poo-2025-Creczuk
Les habilito este medio para entregar el ejercicio que hicimos juntos. Es tomado en cuenta para la nota.

Debe haber en la entrega:
Uso del paquete instanciado en el archivo (package nombreArchivo;).
Declaración de clase Persona.
Declaración de atributos dentro de la clase.
Método constructor.
Getters y setters.
Métodos de la clase (cumplirAnios() y saludar()), funcionales.
Clase Main que cree un objeto para Persona y salude con el objeto.
Para ello, entregar dos archivos: Persona.java y main.Java.
