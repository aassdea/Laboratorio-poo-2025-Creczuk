# Laboratorio-poo-2025-Creczuk
Les habilito este medio para entregar el ejercicio que hicimos juntos. Es tomado en cuenta para la nota.

Debe haber en la entrega:
Uso del paquete instanciado en el archivo.
Declaración de clase Persona.
Declaración de la clase Docente con su herencia instanciada.
Declaración de la clase Estudiante con su herencia instanciada.
Declaración de atributos para cada clase, estableciendo los heredados en Docente y Estudiante con un super.X.
Método constructor para cada clase.
Getters y setters.
Métodos de cada clase funcionales. Método saludar() sobreescrito en Docente y Estudiante para que al saludar muestren sus atributos únicos.
Clase Main que cree un objeto para Persona, uno para Docente y uno para Estudiante. Todos los objetos deben poder saludar y cumplir años. Adicionalmente, cada clase hija debe poder realizar al menos un método alternativo único.
Para ello, entregar estos archivos: Persona.java, Docente.java, Estudiante.java, main.Java.
